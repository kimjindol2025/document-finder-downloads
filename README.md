# Document Finder 다운로드

Windows·Linux x64용 로컬 문서 검색 개발판 배포 저장소입니다. 설치 파일은 Git 이력 대신 Releases에 첨부합니다.

- [다운로드 페이지](https://kimjindol2025.github.io/document-finder-downloads/)
- [0.2.0-dev 설치 파일](https://github.com/kimjindol2025/document-finder-downloads/releases/tag/v0.2.0-dev)

Windows 11 x64 / Ubuntu 24.04 x64를 대상으로 합니다. 코드 서명·확장 스토어 등록은 아직 없으며, Windows 실제 실행과 Chrome/Edge 전체 클릭 검증은 남아 있습니다. Linux 설치 파일의 설치·검색·읽기·진단·제거는 자동 검증했습니다.

브라우저 확장 ZIP도 같은 릴리스에서 제공합니다. Chrome/Edge의 개발자 모드로 압축 해제된 확장을 로드하고, 확장 아이콘을 눌러 연결한 뒤 OS 창에서 폴더를 선택합니다. 로컬 웹 연결 허용 주소는 http://127.0.0.1:30081이며, 공개 다운로드 페이지에서 검색을 실행하지 않습니다.

문서와 색인은 PC에 저장합니다. 자동 업데이트는 지원하지 않습니다. Linux 앱 제거는 ~/.local/share/document-finder/app/uninstall로 실행하며, 앱 데이터와 브라우저 확장 제거는 별도로 관리합니다. 각 파일의 SHA256과 검증 범위는 릴리스의 manifest.json을 확인하세요.
