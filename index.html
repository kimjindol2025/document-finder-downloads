2. 브라우저 확장 설치

이 개발 버전은 확장 ZIP을 내려받아 압축을 풀고, Chrome 또는 Edge의 확장 관리 화면에서 개발자 모드의 ‘압축해제된 확장 프로그램 로드’를 사용합니다. 공개 배포는 확장 스토어를 통해 제공할 예정입니다.

확장 ZIP 다운로드

일반 배포용 설치 완료를 의미하지 않습니다. 개발자 모드가 제한된 환경에서는 사용할 수 없습니다.

사용 안내

검색 기능은 설치한 브라우저 확장 아이콘으로 열 수 있습니다. 연결 시 OS 승인과 검색할 폴더 선택이 필요합니다. 현재 웹 연결 허용 주소는 http://127.0.0.1:30081입니다. 이 공개 페이지는 다운로드 안내 전용이며 검색어·문서를 받지 않습니다.

Linux: 파일 속성에서 실행을 허용하거나 터미널에서 chmod +x document-finder-0.2.0-dev-linux-x64.run 후 실행합니다. Windows: 내려받은 EXE를 실행합니다. 코드 서명 없음·실제 Windows 실행 미검증 상태를 확인하고 사용하세요.

Linux 제거: ~/.local/share/document-finder/app/uninstall. Windows는 앱의 제거 프로그램을 사용합니다. 데이터는 보존합니다. 확장은 브라우저 확장 관리 화면에서 따로 제거합니다.
