1. 로컬 검색기 설치

현재 패키지는 내부 검증용입니다. Windows 설치·Chrome 실제 클릭 검증과 코드 서명은 별도 확인이 필요합니다.

Windows

Windows 11 · x64 · 약 33 MiB

Windows 설치 파일 다운로드

개발판 · 코드 서명 없음 · 실제 Windows 실행 미검증

Linux

Ubuntu 24.04 · x64 · 약 62 MiB

Linux 설치 파일 다운로드

설치 후 실행 권한이 필요합니다. GTK3 데스크톱 환경에서 사용하세요.

버전 0.2.0-dev · GitHub에서 직접 다운로드합니다. SHA256·검증 정보

2. 브라우저 확장 설치

이 개발 버전은 확장 ZIP을 내려받아 압축을 풀고, Chrome 또는 Edge의 확장 관리 화면에서 개발자 모드의 ‘압축해제된 확장 프로그램 로드’를 사용합니다. 공개 배포는 확장 스토어를 통해 제공할 예정입니다.

확장 ZIP 다운로드

일반 배포용 설치 완료를 의미하지 않습니다. 개발자 모드가 제한된 환경에서는 사용할 수 없습니다.

3. 이 브라우저에서 연결

아래 버튼은 설치한 확장을 확인하고 검색 화면을 엽니다. 실제 컴퓨터 접근은 로컬 승인 창과 폴더 선택 후에 시작됩니다.

아직 연결하지 않았습니다.
